# Обучение с учителем: качество модели

**Прогнозирование снижения покупательской активности клиентов интернет-магазина «В один клик».**

## Задача

Построить модель бинарной классификации, которая прогнозирует риск снижения
покупательской активности постоянных клиентов в ближайшие три месяца.
Проанализировать факторы, связанные с этим риском, и выделить прибыльных
покупателей, которым требуется внимание для удержания.

## Данные

- `market_file.csv` — характеристики клиентов и покупательская активность;
- `market_money.csv` — выручка за три периода;
- `market_time.csv` — время на сайте за периоды;
- `money.csv` — прибыль покупателей.

**Важно:** исходные CSV-файлы пока не добавлены в публичный репозиторий.
Для повторного запуска нужно получить исходные файлы и убедиться, что
их разрешено публиковать. Файлы следует разместить в `data/`.
Ноутбук также поддерживает стандартный путь Практикума `/datasets`.

## Что сделано

1. Загрузка данных, проверка пропусков, типов и дубликатов.
2. EDA, исследование распределений и корреляционный анализ Спирмана.
3. Выделение клиентов, совершавших покупки в каждом из трёх месяцев
   (1297 клиентов в сохранённом анализе).
4. Объединение таблиц и подготовка признаков с `ColumnTransformer`.
5. Обучение и сравнение `KNeighborsClassifier`, `SVC`,
   `LogisticRegression`, `DecisionTreeClassifier` с подбором
   гиперпараметров через `GridSearchCV`.
6. Интерпретация предсказаний с использованием SHAP.
7. Сегментация по прибыльности и прогнозируемому риску, рекомендации бизнесу.

## Результаты исходного учебного запуска

Основная метрика — **ROC-AUC**.

| Модель | ROC-AUC по кросс-валидации |
| --- | ---: |
| KNeighborsClassifier | 0.9173 |
| SVC | 0.9148 |
| LogisticRegression | 0.8987 |
| DecisionTreeClassifier | 0.8660 |

Лучшая по сохранённым результатам модель — **KNeighborsClassifier**,
`n_neighbors=30`, **ROC-AUC на тесте — 0.9174**.
В целевом сегменте «высокая прибыль / высокий риск» — **80 покупателей
из 325 в тестовой выборке**. Среди важных признаков выделились число
просмотренных страниц, история посещений, просмотренные категории и
доля акционных покупок.

**Примечание:** приведены значения из сохранённых выводов исходного
ноутбука. После переносимости/обновления среды и данных значения
необходимо перепроверить повторным запуском; повторный полный прогон
пока не выполнялся из-за отсутствия исходных CSV.

## Запуск

Рекомендуется Python 3.10+.

```bash
python -m pip install -r requirements.txt
jupyter lab
```

Откройте `supervised_learning.ipynb` и выполните **Restart & Run All**.
При необходимости установите дополнительные системные пакеты для SHAP.
